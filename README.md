# FruitDrinks
Nesse projeto será desenvolvido a home para apresentação de sabores de deliciosos sucos de frutas. Nele utilizarei as tecnologias Html5, css3 e Javascript. O mesmo está sendo desenvolvido na plataforma linux, com o editor de código sublime, saindo um pouco da zona de conforto do VSCode e me desafiando com um projeto em outras plataformas.
